# Remove-PmTenantService

## SYNOPSIS

Removes (soft-removes) services from tenants.

## SYNTAX

### __AllParameterSets

```
Remove-PmTenantService [-Path <string[]>] [-LiteralPath <string[]>] [-Tenant] <string[]>
 [-ServiceType] <string[]> [-Confirm] [-WhatIf] [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Removes the services -ServiceType names from the tenants -Tenant selects. A service every tenant always keeps (isAlwaysProvision in Get-PmAvailableService: Orchestrator, Data Service and others on Automation Cloud) cannot be removed; it is refused before anything is sent, since the API would answer success and keep it. The cmdlet asks for confirmation (ConfirmImpact High).

This cmdlet operates on the PSDrive of the UiPathOrch provider. It calls the Organization Management Service ({host}/{organization}/organization_), the API of `uip admin tenants`, which Automation Cloud and Automation Suite have and a standalone Orchestrator does not.

Primary Endpoint: POST /organization_/api/organization/{organizationId}/tenants/{tenantId}/services

Required permissions: Organization administrator.

## EXAMPLES

### Example 1: Remove Test Manager from a tenant

```powershell
PS Orch1:\> Remove-PmTenantService Test2 testmanager
```
